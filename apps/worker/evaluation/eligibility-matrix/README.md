New exact synthetic inputs, frozen before v4 validation: dev 10 / holdout 30.
The first `policy-cases` holdout is now development/regression data after rejecting v3.
This matrix crosses target, limits, evidence, clarification status and comparison state.
Labels are authored in `tools/build_eligibility_matrix.py`; neither the model nor
`support_eligibility` generates them. Hashes are fixed in the manifest.

This is one AI author's synthetic state matrix. Related policy patterns recur across
datasets and splits; unique scene IDs and exact input hashes do not establish semantic
independence, representative users or independent human agreement. A complete run checks
system behavior, not broad model quality, real-photo observations or user utility.

Preserve all earlier results and labels, including failed v3. Model decisions and forced
code decisions have separate denominators. Safe finish is not automatically a violation;
supported ordinary cases separately measure whether useful grooming support is retained.
