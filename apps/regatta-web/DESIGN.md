# Sailing lab / 海上の操船画面

2026-10-22、本人の「本物の海でセーリングしている感じ」を優先し、G1/G2完了前でも描画を改善する依頼を受けた。これは操船・モデル評価の合格を意味しない。

## 方向性

海を画面全体に広げ、帆・水平線・水面の照り返しを主役にする。左は小さな操船盤、右は風向とコース、下は航海計器。海を四角い管理画面のカードに閉じ込めない。

- 海中の青 `#06465e`、波の青緑 `#167a8c`、空 `#bfdce9`、帆の白 `#f8fcfa`、計器の紺 `#102f43`、識別の橙 `#ef8354`。
- Avenir Next / Hiragino Sans。艇速と残り時間はtabular数字、説明は小さく短く。リモートフォントなし。
- 海上に重なる明るい半透明の計器。太い縁・大きい販促見出し・同じカードの反復は使わない。
- 追従は艇を見下ろしすぎず水平線を見せ、艇上視点と俯瞰へ本人の操作で切替。
- 独自shaderの波・空・Fresnel反射・日光、立体の帆とリギン、ヒールと上下動、航走時だけの白い引き波。
- ブローは同じ可視領域を水面shaderで暗く細かくざわつかせる。装飾のランダムな雲で新しい風を生成しない。
- 操船の`sailing-v2`と風の`wind-v2`は変更しない。全演出は描画側。停止したら波と引き波も停止。
- reduced-motionではヒール・上下動・カメラの自動的な揺れを抑える。画質切替でDPR・波の細かさを下げられる。
- 外部画像・HDRI・glTFなし。手続き的なgeometry/shaderで作り、GPU資産・listenerを解放する。

```text
艇のマーク / Snipe AI Regatta                   視点 / 画質 / 言語
操船盤               空・水平線・帆                       風向計
風の条件             波・ブロー・艇                       コース図
開始・停止・舵・帆
                 艇速 / 時間 / 風速 / 針路 / VMG / タック
```

計器と海を重ねる理由は海を広くしながら操船情報を視線移動の少ない場所に置くため。透明感だけの装飾にせず、文字は不透明な下地で読めるようにする。
