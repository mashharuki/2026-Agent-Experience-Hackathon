# Sailing lab / 海上の操船画面

2026-10-22、本人の「本物の海でセーリングしている感じ」を優先し、G1/G2完了前でも描画を改善する依頼を受けた。これは操船・モデル評価の合格を意味しない。

## 方向性

海を画面全体に広げ、帆・水平線・水面の照り返しを主役にする。左は小さな操船盤、右は風向とコース、下は航海計器。海を四角い管理画面のカードに閉じ込めない。

- 海中の青 `#06465e`、波の青緑 `#167a8c`、空 `#bfdce9`、帆の白 `#f8fcfa`、計器の紺 `#102f43`、識別の橙 `#ef8354`。
- Avenir Next / Hiragino Sans。艇速と残り時間はtabular数字、説明は小さく短く。リモートフォントなし。
- 海上に重なる明るい半透明の計器。太い縁・大きい販促見出し・同じカードの反復は使わない。
- 追従は艇を見下ろしすぎず水平線を見せ、艇上視点と俯瞰へ本人の操作で切替。
- 独自shaderの波・空・Fresnel反射・日光、立体の帆とリギン、ヒールと上下動、航走時だけの白い引き波。
- ブローは同じ可視領域を水面shaderで暗く細かくざわつかせる。装飾のランダムな雲で新しい風を生成しない。
- 操船の`sailing-v2`と風の`wind-v2`は変更しない。全演出は描画側。停止したら波と引き波も停止。
- reduced-motionではヒール・上下動・カメラの自動的な揺れを抑える。画質切替でDPR・波の細かさを下げられる。
- 外部画像・HDRI・glTFなし。手続き的なgeometry/shaderで作り、GPU資産・listenerを解放する。

```text
艇のマーク / Snipe AI Regatta                   視点 / 画質 / 言語
操船盤               空・水平線・帆                       風向計
風の条件             波・ブロー・艇                       コース図
開始・停止・舵・帆
                 艇速 / 時間 / 風速 / 針路 / VMG / タック
```

計器と海を重ねる理由は海を広くしながら操船情報を視線移動の少ない場所に置くため。透明感だけの装飾にせず、文字は不透明な下地で読めるようにする。

## 予想・観戦への変更

003では操船盤を予想と順位へ置き換える。開始前は4艇の色・名前・方針を示し、予想を選ぶまで出走できない。
開始後は予想を固定し、順位表は追従対象の選択だけに使う。右側のログは実際の選択・出所・適用状態を短く表示。
画面を操縦するボタンと、艇を操縦するボタンを混ぜない。ユーザーの舵・帆操作は新画面から外す。
実モデルとプレビューはエンジン欄・説明・ログ・フッターに明示する。モデルのconfidenceを勝率やオッズにしない。

## トークンと下限（2026-10-23）

観戦画面の色・文字・角丸は `src/style.css` の `:root` のトークンだけを使う。直書きの色は `style.test.ts` が失敗させる。MUIのテーマ（`main.tsx`）は値を写しているため、`:root` と同時に変える。旧操船画面だけのスタイルは `src/legacy.css`。

| トークン | 値 | 用途 |
| --- | --- | --- |
| `--ink` / `--text-muted` | `#102f43` / `#4b6573` | 本文・数値 / 注記・ラベル |
| `--surface` / `--surface-selected` / `--line` | `#f5fbf9` / `#e2eef0` / `#cedee2` | パネル / 選択行 / 区切り |
| `--brand` / `--accent` / `--positive` / `--info` | `#244d61` / `#ef8354` / `#286b62` / `#276d8c` | 主ボタン / 予想艇・的中 / 実モデル・判断中 / ブロー |
| `--on-sea` / `--scrim` | `#e9f5f6` / `#1d4b5cd9` | 海上の文字 / その下敷き |
| `--focus-ring` / `--focus` | `#b4561b` / `#ffd894` | パネル上 / 海上のフォーカス枠（3:1以上） |
| `--fs-xs`〜`--fs-xl` | 11 / 12 / 14 / 17 / 22px | 文字サイズ（計器の大数字は個別） |
| `--radius-sm` / `--radius-md` | 6 / 10px | 角丸 |

- 文字は11px以上。小さい文字は下地に対して4.5:1以上（テストで検査）。
- 海の上に直接文字を置かない。`--scrim` の下敷きを付ける。
- 予想艇は順位表・判断ログ・結果で `--accent` の縦線と「予想」の札で示す。
