## 修正結果

| 指摘 | 実装と証拠 |
| --- | --- |
| R1：禁止事項 | 相談画面の選択値をAPIへ送信。APIで正規化し、workerの選択・説明ガードへ渡す。画面のリクエスト検査と既存の禁止行動・説明拒否テストで確認 |
| R2：確認質問 | CLARIFYING、回答API、構造化質問、回答フォームを追加。対象を覆う10分以内の観察を再利用。APIで認可・期限・同じ回答の再送を検証し、workerで回答内容の反映・再観察0回・メモ削除を検証 |
| R3：部分保存 | 共通Storeにトランザクションを追加。解析受付とセッション作成を原子的に確定。保存前の例外・コミット後の応答喪失・競合・孤立した旧レコードをmemory/motoで検証 |
| R4：待機と終了 | HTTP/S3の期限、独立60秒タイマー、GETエラーと再確認、AbortSignal、世代による遅延応答の抑制。終了直後の再開始に旧セッションの応答が混ざらないことも検証 |
| R5：画像削除 | 部分失敗の検出、件数の分離、最大2回の追加再試行、残り時間の確認、CloudWatch通知、期限切れメモ回収を追加。S3のfake/motoとCDK assertionsで検証 |
| R6：モック | 描画開始前に実行環境を一度生成。StrictModeの実画面操作と生成クライアントでシナリオの一致を検証 |
| R7：品質・文書 | Knipのentryと生成コードの扱いを修正、未使用turboを削除。CDKの出力をdistへ分離しビルド後の誤検出も解消。GitHub ActionsとPlaywrightを追加。AGENTS、技術一覧、README、Spec Kit、運用・検証手順を更新 |

- 同意文は `2026-10-v2`。観察メモの用途・最大10分の利用・削除方針を明記した。10分は利用期限で、TTLの物理削除時刻の保証ではない。
