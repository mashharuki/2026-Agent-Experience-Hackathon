# 観戦画面デザイン改善: 検証記録

2026-10-23 / 計画: [design-improvement-plan.md](../../specs/003-regatta-spectator/design-improvement-plan.md) / ブランチ `003-spectator-design`

表示だけの変更。物理・風・判断（`sailing-v2` / `wind-v2` / `fleet-v4`）と順位の並び順は変えていない。`sailing-sim` には既存の残距離計算を `fleetRemaining` として公開しただけ。

## 変更内容

1. 結果画面：的中／外れ／不成立、自分の予想と勝者を最初に示し、着順（予想艇に「予想」の札）とコース図・振り返りスライダーを横並びにした。的中時の演出は reduced-motion で止まる。
2. 予想艇の強調：順位表・判断ログで予想艇に縦線と札を付けた。順位表の右側は艇速から先頭との差（m）へ変更。計器は「残り時間」「予想艇の順位」を大きくし、艇速・針路に追従艇名を付けた。判断ログは戦術の種類の記号と、出所のバッジを表示する。
3. トークン：色・文字・角丸を `:root` のトークンに統一した。文字は11px以上、海上の文字には下敷きを付けた。旧操船画面だけのスタイルは `legacy.css` に移した。
4. 3D上の艇名ラベル：画面外・カメラ背後では非表示。予想艇には★と枠を付けた。
5. 操作パネル：出走前は「予想→出走」を上に置き、設定は折りたたむ（見出しに現在の判断エンジンを表示）。レース中は見出しを隠した。「レースを終了」には確認を挟む。接続状態はバッジで示す。
6. 押せる要素はスマホで44px以上、PCの表示切替は36px。コース図は200pxに広げ、押すと360pxに拡大する。

## 目視確認

ヘッドレスChromiumで、出走前・レース中（追従／俯瞰）・結果を1440×900と390×844で、英語表示を1440×900で確認した。ヘッドレスはソフトウェア描画のため fps は約10で、ラベル追加の前後で差はなかった。実GPUでのfps、実機スマホ、実モデル（Decider）接続時の表示は未確認。

## 最終レビューで直した点

- 1艇が完走した後に、2位の艇へ「先頭」が付いていた。完走艇がいる間は「先頭」を出さず、レース終了後の未完走艇は「未完走」と表示する。
- フォーカス枠のコントラストが不足していた。パネル上は `--focus-ring`（`#b4561b`）、海上は `--focus`（`#ffd894`）に変え、どちらも3:1以上であることをテストで確認する。

## 残る課題

- 俯瞰で艇が密集すると艇名ラベル同士が重なる（スタート直後など）。
- 高さ850px以下のPCでは、従来どおりコース図を隠している。
- 時間切れを再現するE2Eは約1.7分かかり、CIの時間が延びる。
- 軽微なため見送った指摘：コース図ボタンの名前が二重に読み上げられる、TSX内に色の直書きが残る、同着の勝者が着順で1位・2位と番号付けされる、英語の「Your pick」が札と計器の両方で使われている、ダイアログ内で見出しh2が入れ子になっている。
